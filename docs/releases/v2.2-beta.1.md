# Shopping List Calculator 2.2-beta.1

Opt-in maintenance beta; not a stable release.

- Migrates Settings to Kotlin while retaining the Android Views interface.
- Fixes budget/currency settings handling and adds regression coverage.
- Enables R8 code and resource shrinking. No networking or tracking added.
- Preserves jubayer10010’s original contribution and commits.

## Installation and testing

Download the signed APK from the GitHub prerelease and install it over version 2.1. The production package and signing key are unchanged; version code is 17. Do not uninstall or clear storage. Record important lists/settings first: returning to older stable code 16 may require uninstalling and losing local data. The later stable release must use a higher version code.

Check existing lists and totals, settings persistence, budget and custom currency handling, weight units, editing/saving lists, and restarting the app. Report device/Android version and reproduction steps; do not include private shopping data.

## Publication gates

Do not publish the beta tag until F-Droid’s stable-only tag filter has been accepted and reverified upstream. GitHub’s prerelease flag alone does not exclude tags from F-Droid.

Build/sign from this exact commit and verify certificate, package, version, and embedded revision. A production 2.1-to-beta upgrade test is required before publication; prior debug-upgrade testing is not equivalent.
