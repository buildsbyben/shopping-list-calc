# Shopping List Calculator 2.3

- Fixed the crash caused by rapidly tapping **+ Item**.
- Fixed the Settings budget field opening a text keyboard instead of a numeric/decimal keyboard.
- Completed the Kotlin migration while retaining the native Android Views interface and small, offline app design.
- Existing current lists, saved name-only templates, and settings retain their storage formats.

Thanks to @jubayer10010 for reporting #10 and verifying the fixes on Samsung Galaxy S21 FE / Android 16 / One UI 8.

This release does not include the optional saved-list prices and quantities feature in #8 / #18; that work remains under review.

## Distribution

The stable APK uses the existing application ID and signing key and can update earlier stable versions. The separate Shopping Calc TEST app is not replaced.

F-Droid availability follows its independent review/build process. GitHub publication is not confirmation of F-Droid availability.
