# Shopping Calc TEST 2.2-kotlin-test.2

Public testing prerelease of the complete Kotlin conversion using the existing Android Views UI.

## Changes

- Includes the Kotlin regression baseline, models/helpers, storage, and MainActivity migrations from PRs #13–#16.
- Fixes stale focus/scroll callbacks after rapid **+ Item** taps, the crash under investigation in issue #10.
- Requests a decimal keyboard for the Settings budget field while preserving formatted currency text.

## Installation

Download `shopping-calc-2.2-kotlin-test.2.apk` from the matching GitHub prerelease and install it on Android 6.0 or newer. Android may ask you to allow installation from your browser or file manager.

This is a debug-signed testing build named **Shopping Calc TEST**, package `io.github.buildsbyben.shoppinglistcalc.dev`, version code 19. It installs separately from the official app, uses separate data, and updates the previous `2.2-kotlin-test.1` TEST build. It does not import your official app's lists. Keep the official app for real shopping lists.

This is not a stable release or an F-Droid update. Production version metadata remains unchanged.

- Add, edit, check off, and delete items; check quantities, prices, tax, budget, and totals.
- Save and reopen lists, change settings, and rotate the screen.

Report device model, Android version, this build version, reproduction steps, and any crash details. A successful retest on the original reporter's device is still needed before considering the crash resolved there.
